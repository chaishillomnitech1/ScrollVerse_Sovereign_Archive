# ScrollVerse Archive Logs

**بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ**

## Overview

This directory contains immutable historical logs for the ScrollVerse Sovereign Archive. All logs are structured, timestamped, and maintain cryptographic integrity.

## Directory Structure

```
logs/
├── acquisitions/        # Asset acquisition records
├── protocols/          # Protocol modification logs
├── events/            # System event logs (JSONL format)
└── audits/            # Audit reports (generated by workflows)
```

## Log Types

### 1. Acquisition Logs (`acquisitions/`)

**Format**: `acquisition_YYYY-MM-DD_HHmmss.json`

**Purpose**: Records all asset acquisitions and registrations

**Schema**:
```json
{
  "logId": "ACQ-{timestamp}-{sequence}",
  "timestamp": "ISO-8601 UTC",
  "acquisitionType": "ASSET|PROTOCOL|CONTRACT",
  "assetDetails": { ... },
  "verification": { ... },
  "integration": { ... }
}
```

**Template**: See `.template_acquisition.json` for structure

### 2. Protocol Logs (`protocols/`)

**Format**: `protocol_change_YYYY-MM-DD_HHmmss.json`

**Purpose**: Documents all protocol modifications and enhancements

**Schema**:
```json
{
  "logId": "PROT-{timestamp}-{sequence}",
  "timestamp": "ISO-8601 UTC",
  "protocolName": "Name of protocol",
  "changeType": "ENHANCEMENT|BUGFIX|SECURITY",
  "description": "Detailed description",
  "impact": "CRITICAL|HIGH|MEDIUM|LOW",
  "approvalChain": [ ... ]
}
```

### 3. Event Logs (`events/`)

**Format**: `event_YYYY-MM-DD.jsonl` (JSON Lines)

**Purpose**: Real-time system events and operational records

**Schema** (per line):
```json
{"eventId":"EVT-001","timestamp":"ISO-8601","type":"EVENT_TYPE","status":"STATUS","details":"Description"}
```

**Event Types**:
- `VALIDATION`: Integrity check events
- `AUDIT`: Audit execution events
- `SYSTEM_INIT`: System initialization
- `WORKFLOW`: Workflow execution
- `ALERT`: Alert and notification events

### 4. Audit Logs (`audits/`)

**Format**: `AUDIT-{date}-{time}-{run}.md`

**Purpose**: Comprehensive audit reports (auto-generated)

**Generated By**: GitHub Actions workflows
- Archive Integrity Validation
- Periodic Audit and Compliance

## Usage Guidelines

### Creating New Logs

1. **Use appropriate template** for the log type
2. **Generate unique ID** following the format convention
3. **Include timestamp** in ISO-8601 UTC format
4. **Validate JSON** before committing
5. **Follow naming convention** for file names

### Log Immutability

Once a log is committed:
- ✅ Can be referenced
- ✅ Can be replicated
- ❌ Cannot be modified
- ❌ Cannot be deleted

Any corrections require a new log entry with reference to the original.

### Querying Logs

**Find acquisitions by date**:
```bash
ls logs/acquisitions/acquisition_2025-11-*.json
```

**Search event logs**:
```bash
grep "VALIDATION" logs/events/event_2025-11-12.jsonl
```

**View protocol changes**:
```bash
cat logs/protocols/protocol_change_*.json | jq '.protocolName'
```

## Retention Policy

- **Acquisitions**: Permanent (immutable archive)
- **Protocols**: Permanent (immutable archive)
- **Events**: Minimum 7 years
- **Audits**: Permanent (compliance requirement)

## Integrity Verification

All logs are included in the repository-wide checksum validation:

```bash
# Verify log integrity
sha256sum logs/**/*.json > logs_checksums.txt
sha256sum -c logs_checksums.txt
```

Checksums are automatically updated by GitHub Actions workflows.

## Examples

### Create Acquisition Log

```bash
timestamp=$(date -u +%Y-%m-%dT%H:%M:%SZ)
filename="logs/acquisitions/acquisition_$(date -u +%Y-%m-%d_%H%M%S).json"

cat > "$filename" << EOF
{
  "logId": "ACQ-$(date +%s)-001",
  "timestamp": "$timestamp",
  "acquisitionType": "ASSET",
  "assetDetails": {
    "name": "Example Asset",
    "value": "1000000",
    "category": "Digital Twin"
  }
}
EOF
```

### Append Event Log

```bash
date=$(date -u +%Y-%m-%d)
echo "{\"eventId\":\"EVT-$(date +%s)\",\"timestamp\":\"$(date -u +%Y-%m-%dT%H:%M:%SZ)\",\"type\":\"VALIDATION\",\"status\":\"SUCCESS\",\"details\":\"Manual validation completed\"}" >> "logs/events/event_$date.jsonl"
```
